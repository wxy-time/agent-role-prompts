# 变更记录

## [0.2.3] - 2026-08-19

- 运行对账扩展：子 Issue 无活动执行且未写出合法结果时，仅 run 被取消或查不到 run 记录的可自动 rerun 一次，其余状态直接 FAILED_SAFE 上报人工，不再无限等待。
- METADATA_PERSIST_FAILED 紧急释放协议：子角色以该标记结束 Issue 且评论含原拟结论与直接证据时，调度者直接按评论结论路由，不再作为字段缺失机械重试、不占用重试预算。
- 环境失败重试守卫：RETRYABLE_FAILURE / environment 重试前先核对环境就绪证据，证据未变化直接 FAILED_SAFE。
- 集成冲突收敛上限：同一集成冲突重做 2 次仍失败即 FAILED_SAFE，涉及他人改动的合并决策交人工处理。

## [0.2.2] - 2026-08-19

- 单单元小 STANDARD 任务可跳过独立计划评审，由调度者派工前核对计划；FULL、多单元拆分、公共契约、迁移、资金等高风险改动保留独立评审。
- identity_contract_matrix 仅 FULL 任务要求；复用既有隔离机制的 STANDARD 任务只写接口级隔离冒烟断言。

## [0.2.1] - 2026-08-19

- 验收默认只保留一轮 CANDIDATE 独立验收；集成合并改为调度者机械检查（ancestry、目标引用、冲突区域复核和集成点组合构建），仅非平凡合并按需补一次 INTEGRATION 验收。

## [0.2.0] - 2026-08-19

- 验证级别按实际影响面分级：只有实际修改 schema/迁移/RLS、公共 API 契约结构或认证/权限判断逻辑才升 FULL；复用既有隔离机制的任务降为 STANDARD，只做接口级隔离冒烟。
- 构建与回归按受影响包定向（含共享包的反向依赖闭包），纯后端改动不跑前端构建，全仓全量构建移到集成点统一执行一次。
- 保留前端代码层测试，改为按 diff 定向执行，不删除。

## [0.1.1] - 2026-08-11

- 将中英文文档拆分到独立路径。
- 增加全 Git 历史和提交元数据隐私审计。
- 使用 GitHub noreply 身份替换提交历史中的私人邮箱。

## [0.1.0] - 2026-08-11

- 发布五个独立角色提示词和三种验证级别。
- 增加 MIT License、公开合成场景、静态协议评估和公开制品隐私检查。
